A Few Things We Both Like

  • Reading with tea instead of coffee, always
  • Annotating books in pencil, never pen
  • Dim lighting and a genuinely quiet room
  • Old libraries more than new bookstores

How This Project Came Together

  1. We agreed on a theme — a shared "book excerpt" journal — before writing any code.
  2. We split the four pages evenly and sketched the layout on paper first.
  3. We built one shared stylesheet so every page would feel consistent.
  4. We tested every link and image path before calling a page finished.
